### To-Do App

Application **To-Do full-stack** permettant de gérer des tâches quotidiennes à travers une interface moderne et une API backend.

---

#### 🎯 Description

Cette application permet aux utilisateurs de créer et gérer une liste de tâches. Elle met en pratique une architecture **frontend / backend** avec communication via une API REST.

---

#### 🚀 Fonctionnalités

* Ajouter une nouvelle tâche
* Modifier une tâche existante
* Supprimer une tâche
* Marquer une tâche comme terminée
* Interface simple et réactive

---

## 🛠️ Technologies

* **Frontend** : React + Vite
* **Backend** : Node.js, Express.js
* **API** : REST

---

#### 📥 Cloner le projet

```bash
git clone https://github.com/BenNasserHajer/To-Do-App.git
```

---

#### ▶️ Lancer le projet

